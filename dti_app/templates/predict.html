Predict Drug–Target Binding Affinity

Evaluate how strongly a small-molecule drug candidate binds to a target protein pocket. The neural network computes independent values for pKi (equilibrium dissociation) and pIC50 (50% functional inhibition) using Graph Neural Networks and ESM-2 representations.

What This Function Means

Estimates the quantitative interaction potency between a chemical graph and an evolutionary protein sequence embedding.

Required Inputs

1. Drug: SMILES string (e.g. Erlotinib).
2. Target: UniProt ID (e.g. P00533) or full amino-acid sequence.

Conclusion & Interpretation

Values ≥ 8.0 indicate nanomolar potency (≤ 10 nM). The system flags novel scaffold uncertainty based on test RMSE.
